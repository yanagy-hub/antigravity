# Loop Guardrail Skill

## 概要
AIの自律ループにおいて、「同じ試行を繰り返して堂々巡りになっていないか」「指定した最大試行回数を超えていないか」をチェックするためのスキルです。

## 使用タイミング
* ループ処理（自律修正や探索など）の「観察（Observe）」または「評価（Evaluate）」の最初。
* 各イテレーションの開始時に呼び出し、実行を継続すべきか判断する際に使用します。

## 使用方法
以下のスクリプトを呼び出して、状態を記録・チェックします。

```bash
# 実行コマンドの例 (max_iterations を 3 に設定して "bugfix-task-1" を実行)
python 90_System/91_Scripts/loop_guardrail.py --task-id "bugfix-task-1" --max-iterations 3
```

### 引数
* `--task-id`: 追跡したいループ処理の一意なID。
* `--max-iterations`: 許可される最大のループ回数。

### 動作
* 上限を超えていない場合は `0` で終了し、現在のイテレーション回数を標準出力に出します。
* 上限に達した場合（無限ループの疑いがある場合）は `0` 以外のステータスコードを返し、ループを強制停止すべき旨の警告を出力します。
