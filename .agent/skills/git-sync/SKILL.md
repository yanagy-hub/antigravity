# Git Sync Skill

## 概要
ユーザーからGit操作（同期、コミット、プッシュ等）が依頼された際、ステップごとの細かい「`git status` していいですか？」「`git diff` していいですか？」という事前確認を省略し、ステータス確認と差分解析を自動で実行して、一括承認依頼（変更概要＋提案コミットメッセージ＋一括実行の可否）を提示します。

## 適用タイミング
* ユーザーが「gitをお願い」「git同期して」「コミットして」「pushして」等のリクエストを行った時。

## 動作フロー

### Step 1: 自律的な状況把握（一括実行）
* 個別の事前確認を行わずに `python 90_System/91_Scripts/git_sync.py` または `git status` / `git diff` を自律実行し、変更ファイルおよび差分内容を把握します。

### Step 2: 一括提案と1回のみの承認確認
ユーザーに対して以下の情報をまとめたメッセージを提示し、**一括での実行許可**を求めます。
1. **変更ファイル一覧**
2. **変更内容の要約（サマリー）**
3. **提案するコミットメッセージ**
4. **一括実行する予定のコマンド**
   - `git add .`
   - `git commit -m "<提案コミットメッセージ>"`
   - `git push origin <現在のブランチ>`

### Step 3: 一括実行と完了報告
ユーザーから「OK」「おｋ」「実行して」等の承認を得たら、一括して上記のGitコマンドを順次実行し、最終結果（コミットID、プッシュ結果）を報告します。
