# Auto-Rollback & Regression Checker Skill

## 概要
AIの自律修正ループにおいて、修正を加えたことで「今まで通っていたテストが落ちるようになった（デグレ）」状態を検知します。
デグレを検知した場合は、AIに対して直前の状態にロールバック（復元）するよう警告と具体的なコマンドを提示します。

## 使用タイミング
* ループエンジニアリングの「評価（Evaluate）」フェーズにおいて、テストを実行した直後。

## 使用方法
現在のテスト結果における「成功した数（Passed）」と「失敗した数（Failed）」を引数に渡して実行します。

```bash
# 実行例: 成功が10件、失敗が2件の場合
python 90_System/91_Scripts/regression_checker.py --passed 10 --failed 2 --files-changed src/main.py
```

### 引数
* `--passed`: 今回のテスト実行で成功（Passed）した件数。
* `--failed`: 今回のテスト実行で失敗（Failed）した件数。
* `--files-changed`: 今回のループで変更したファイル（カンマ区切り）。復元コマンドの提案に使用されます。
* `--reset`: 記録されている履歴をリセットして最初からカウントし直します。

### 動作
* 前回のテスト実行時の `passed` 数と比較し、今回の `passed` 数が**減っている場合**は「デグレが発生した」とみなし、1 以外の終了コードを返します。
* エラー出力として `git checkout -- src/main.py` などのロールバックコマンドを提案し、破壊的修正の連鎖を防ぎます。
